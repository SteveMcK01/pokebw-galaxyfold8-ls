# Repository Workflow Rules (`pokebw-galaxyfold8-ls`)

- **Base Engine & Decomp Pairing:** Native Android port of *Pokémon Black* & *Pokémon White* built on `eidos` (`~/pokebw-galaxyfold8-ls`, branch `bw-fold`) paired with sibling decompilation repo `~/aletheia` (`-DALETHEIA_ROOT=../aletheia`).
- **Target Platform:** Android `arm64-v8a` only (optimized for Samsung Galaxy Z Fold & phones). Do not run or suggest desktop builds unless explicitly requested.
- **Terminal Safety:** Always wrap multi-step shell scripts in a subshell `( ... )` and avoid top-level `set -e`.
- **Git & CI Workflow:** Every completed change should update `AGENTS.md`, commit cleanly, and push to `origin bw-fold`.
- **Android CI Pipeline (Phase 0.2):** `.github/workflows/build_android.yml` builds the two-stage `arm64-v8a` APK (`eidos_boot.wasm` via `wasi-sdk`, then `android/build.py` via NDK + Gradle) against `SteveMcK01/aletheia` (`main`), sets `VERSION_CODE=$((9200000 + RUN_NUMBER))` and `VERSION_NAME=<short-sha>` via `android/app/build.gradle` env overrides, prioritizes `google()` and Google's Maven Central mirror before `mavenCentral()` in `android/build.gradle` to prevent CI HTTP 429 errors, signs release APKs persistently using configured `ANDROID_KEYSTORE`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, and `ANDROID_KEY_PASSWORD` secrets on `SteveMcK01/pokebw-galaxyfold8-ls` (enabling in-place APK upgrades; falling back to debug if unset), uploads `pokebw-android` + `libmain.so` symbols, and publishes the rolling `bw-fold-android-latest` prerelease on pushes to `bw-fold`.
- **Android On-Screen Touch Controls:** Native GLES 3.0 virtual DS controller in `host/touch_controls.c` / `host/touch_controls.h` (hooked into `host/sdl.c` and linked with `GLESv3` in `host/CMakeLists.txt`; `host/main.c` forces `EIDOS_RENDERER=gl` on Android so the GLES 3.0 swap hook always runs) provides multi-touch D-pad, A/B/X/Y, L/R, START/SELECT, and top-center `PAD` + `MENU` pills while allowing simultaneous DS bottom-screen stylus touches.
- **Dear ImGui Overlay & Persistent Settings (Phase 0.3):** `tools/fetch_imgui.py` downloads Dear ImGui v1.93.0 (wired via `-DEIDOS_HOST_IMGUI_ROOT` and `-DANDROID_STL=c++_static` in `android/build.py` / `host/CMakeLists.txt`). `host/imgui_overlay.cpp` renders the touch-scaled GLES 3.0 settings menu + FPS badge over SDL3, backed by `<profile_dir>/pokebw_settings.ini` (`host/pokebw_settings.c`) and exposed to the wasm32 game module via `bw_host_setting_get` (`sdk/wasm_host.h`, `sdk/pokebw_settings_ids.h`).
- **Phase 1.1 (Trade Evolution Fixes):** `sdk/pokebw_trade_evo.c` wraps `SHINKA_CHECK_CheckEvolution` via `-Wl,--wrap=SHINKA_CHECK_CheckEvolution` in `CMakeLists.txt` (controlled by `POKEBW_SET_TRADE_EVO_FIX`) to allow pure trade evolutions at Lv. 36+, held-item trade evolutions on level-up with the item, and Karrablast/Shelmet evolutions with the counterpart in party or Lv. 36+; `engine/platform/text_instant.c` also honors `POKEBW_SET_INSTANT_TEXT`.
- **Phase 1.2 (Modern EXP Share):** `sdk/pokebw_exp_share.c` wraps `ov093_BTL_SERVER_FLOW_CalcPartyExpShares` via `-Wl,--wrap=ov093_BTL_SERVER_FLOW_CalcPartyExpShares` in `CMakeLists.txt` (controlled by `POKEBW_SET_MODERN_EXP_SHARE`) to grant 100% defeat EXP to all battle participants and 50% to non-fainted bench members while preserving Gen 5 level scaling, trainer/OT/Lucky Egg/Pass Power multipliers, and EV yields.
- **Phase 1.3 (HM Without Teaching / HM Freedom):** `sdk/pokebw_hm_free.c` wraps `ov010_SCRCMD_PROC_FindPartyMonWithMove`, `ov091_PLIST_MENU_BuildCommandList`, and `ov091_POKELIST_DispatchMenuChoice` in `CMakeLists.txt` (controlled by `POKEBW_SET_HM_FREEDOM` and `POKEBW_SET_HM_NO_BADGES`) to allow Cut, Fly, Surf, Strength, Waterfall, Dive, and Flash from any compatible non-Egg party member without occupying a moveslot.
- **Phase 1.4 (Gotta Catch 'Em All! Mode):** `sdk/pokebw_catch_em_all.c` wraps `ov010_FIELD_ENCOUNT_ST_LoadEncountData` via `-Wl,--wrap=ov010_FIELD_ENCOUNT_ST_LoadEncountData` in `CMakeLists.txt` (controlled by `POKEBW_SET_CATCH_EM_ALL`) to merge Black/White version exclusives, inject Gens 1–4 National Dex species, and enable built-in Victini/Zorua/Zoroark/Keldeo/Meloetta/Genesect/opposite-legendary encounters.
- **Phase 1.5 Resolution (Native `eidos` One-Screen Mode + Unified ImGui Settings Bridge):** Replaced custom Engine B PiP with `eidos`'s built-in `One screen` mode (`EIDOS_LAYOUT_ONE`, widescreen 3D + 15 UI recipes + `C-GEAR` sheet) and added a two-way wasm↔host option sync (`eidos_opt_sync` / `eidos_opt_poll` in `sdk/wasm_host.h`, `engine/platform/settings.c`, `host/pokebw_settings.c`, `host/main.c`) so `eidos` layout, interface theme, 3D resolution, battle visuals, volume, instant text, and map transitions can be configured live in `host/imgui_overlay.cpp`.
- **Phase 1.6 (Portable PC Box Access):** `sdk/pokebw_portable_pc.c` wraps `ov021_FIELD_EVENT_CHECK_RunGrid` and `ov021_FIELD_EVENT_CHECK_RunRail` via `-Wl,--wrap` in `CMakeLists.txt` (controlled by `POKEBW_SET_PORTABLE_PC` and triggered via `pc_request_poll` / `pc_request_result` in `sdk/wasm_host.h`, `host/pokebw_settings.c`, `host/main.c`, and `host/imgui_overlay.cpp`) to launch Unova's `BoxApp` (`ov170`, Organize Boxes or Move Items) with overworld safety guardrails.
- **Custom External Save Folder & QoL Cleanup:** Removed `Universal TM/HM Compatibility` from the QoL menu and added a `Choose Save Folder...` / `Reset to Default` workflow (`AndroidManifest.xml`, `EidosActivity.java`, `host/pick_mobile.c`, `host/pokebw_settings.c`, `--save-dir` in `demo/eidos_boot.c`, and `save_dir_poll` in `sdk/wasm_host.h` / `engine/platform/settings.c`) so players can keep standard 512 KiB `pokeblack.sav` files in user-accessible folders (e.g., for PKForge).
- **Phase 2.1 (QoL & Cheats):** Added Hard Level Cap (`sdk/pokebw_exp_share.c` wrapping `ov093_BTL_SERVER_FLOW_CalcPartyExpShares` with Unova badge caps `{14,20,23,27,31,35,39,43,54}` via `POKEBW_SET_HARD_LEVEL_CAP`) and `sdk/pokebw_qol.c` (wrapping `GAME_DATA_GetSeason`, `GF_STANDARD_GetCachedTime`, `GF_STANDARD_CopyCachedRtc`, `GF_STANDARD_GetSecondsOfDay`, `ov021_FIELD_ENCOUNT_CheckWildEncount`, `ov021_FIELD_ENCOUNT_CheckWfbcEncount`, and `ov021_FIELD_ENCOUNT_CheckFishingEncount` in `CMakeLists.txt` for `POKEBW_SET_NO_RANDOM_ENCOUNTERS`, `POKEBW_SET_ALWAYS_BITE_FISHING`, `POKEBW_SET_SEASON_OVERRIDE`, and `POKEBW_SET_CLOCK_OVERRIDE`), all configurable live in `host/imgui_overlay.cpp`.
- **Phase 2.2 (Gen 5 Battle HUD Enhancements):** Added live Gen 5 move-card type-effectiveness pills (`4x`, `2x`, `1/2`, `1/4`, `0x`) in `engine/ui/recipe_battle.c` via `k_gen5_type_chart`, `single_active_foe`, `battle_eff_x4`, and `draw_eff_pill` (preserving Gen 5 Steel resisting Ghost/Dark, skipping status moves, hiding Illusion-masked targets, applying Mold Breaker/Turboblaze/Teravolt/Scrappy, and honoring Levitate/Flash Fire/Water Absorb/Dry Skin/Storm Drain/Volt Absorb/Motor Drive/Lightningrod/Sap Sipper/Wonder Guard/Thick Fat/Heatproof), controlled by `POKEBW_SET_TYPE_EFFECTIVENESS` (`Battle Effectiveness Pills` in `host/imgui_overlay.cpp` / `host/pokebw_settings.c`).
- **Phase 2.3 (Gear Companion & Unova Route Radar):** Added live `gear_push` wasm→host telemetry (`sdk/pokebw_gear_state.h`, `sdk/pokebw_gear.h`, `sdk/pokebw_gear.c`, wired from `sdk/pokebw_catch_em_all.c`, `sdk/pokebw_portable_pc.c`, `sdk/wasm_host.h`, `host/main.c`, and `CMakeLists.txt`) feeding the **Gear** tab in `host/imgui_overlay.cpp`: live party move-pill cards, Unova Route Radar across all 7 habitats (Seasons, Dark Grass, Phenomena, Surfing, Rippling Water, Fishing, Rippling Fishing, Pokédex `[Caught]`/`[Seen]`/`[New]`), and 3 atomic `.sav` backup/restore slots in `<effective_save_dir>/backups/` via `host/pokebw_settings.c`.
- **Phase 3.1 (649-Species Overworld Sprite Archive):** Added `tools/pack_ow_sprites.py` (encodes 4×4/4×2/2×4/1×8 PNG sheets, `.nsbtx`/`.btx0`, and lossless 4bpp indexed `overworld.png` + `JASC-PAL` strips into compact `BWSP` packs + self-test), `tools/fetch_ow_sprites.py` (sparse-checkouts `rh-hideout/pokeemerald-expansion` `expansion/1.17.2` and packs all 649 normal + 649 shiny + 164 Gen 5 alternate forms into `android/app/src/main/assets/pokebw_ow_sprites.bwsp` during `.github/workflows/build_android.yml` Stage 2), and `sdk/pokebw_ow_sprites.h` / `sdk/pokebw_ow_sprites.c` (registered in `demo/eidos_boot.c` after `avatar_field_register` and wired into `CMakeLists.txt` with `-Wl,--wrap=ov010_FLDMMDL_LoadObjCodeParam`) to load `pokebw_ow_sprites.bwsp` (extracted from APK assets by `EidosActivity.java`), synthesize fallback 8-frame `32×256` `BTX0` sprites from `a/0/0/7` for any remaining species/forms into `a/0/4/9` via `bw_vfs_mem_set`, and expose sprite counts in `PokebwGearSnapshot` (`host/imgui_overlay.cpp`).
