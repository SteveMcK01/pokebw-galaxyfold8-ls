# Repository Workflow Rules (`pokebw-galaxyfold8-ls`)

- **Base Engine & Decomp Pairing:** Native Android port of *Pokémon Black* & *Pokémon White* built on `eidos` (`~/pokebw-galaxyfold8-ls`, branch `bw-fold`) paired with sibling decompilation repo `~/aletheia` (`-DALETHEIA_ROOT=../aletheia`).
- **Target Platform:** Android `arm64-v8a` only (optimized for Samsung Galaxy Z Fold & phones). Do not run or suggest desktop builds unless explicitly requested.
- **Terminal Safety:** Always wrap multi-step shell scripts in a subshell `( ... )` and avoid top-level `set -e`.
- **Git & CI Workflow:** Every completed change should update `AGENTS.md`, commit cleanly, and push to `origin bw-fold`.
- **Android CI Pipeline (Phase 0.2):** `.github/workflows/build_android.yml` builds the two-stage `arm64-v8a` APK (`eidos_boot.wasm` via `wasi-sdk`, then `android/build.py` via NDK + Gradle) against `SteveMcK01/aletheia` (`main`), sets `VERSION_CODE=$((9200000 + RUN_NUMBER))` and `VERSION_NAME=<short-sha>` via `android/app/build.gradle` env overrides, prioritizes `google()` and Google's Maven Central mirror before `mavenCentral()` in `android/build.gradle` to prevent CI HTTP 429 errors, signs release APKs persistently using configured `ANDROID_KEYSTORE`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, and `ANDROID_KEY_PASSWORD` secrets on `SteveMcK01/pokebw-galaxyfold8-ls` (enabling in-place APK upgrades; falling back to debug if unset), uploads `pokebw-android` + `libmain.so` symbols, and updates the rolling `bw-fold-android-latest` prerelease in place (`gh release upload --clobber` + `gh release edit`) on pushes to `bw-fold`.
- **Android On-Screen Touch Controls:** Native GLES 3.0 virtual DS controller in `host/touch_controls.c` / `host/touch_controls.h` (hooked into `host/sdl.c` and linked with `GLESv3` in `host/CMakeLists.txt`; `host/main.c` forces `EIDOS_RENDERER=gl` on Android so the GLES 3.0 swap hook always runs) provides multi-touch D-pad, A/B/X/Y, L/R, START/SELECT, and top-center `PAD` + `MENU` pills while allowing simultaneous DS bottom-screen stylus touches.
- **Dear ImGui Overlay & Persistent Settings (Phase 0.3):** `tools/fetch_imgui.py` downloads Dear ImGui v1.93.0 (wired via `-DEIDOS_HOST_IMGUI_ROOT` and `-DANDROID_STL=c++_static` in `android/build.py` / `host/CMakeLists.txt`). `host/imgui_overlay.cpp` renders the touch-scaled GLES 3.0 settings menu + FPS badge over SDL3, backed by `<profile_dir>/pokebw_settings.ini` (`host/pokebw_settings.c`) and exposed to the wasm32 game module via `bw_host_setting_get` (`sdk/wasm_host.h`, `sdk/pokebw_settings_ids.h`).
